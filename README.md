# DSA Practice Platform (LeetCode Clone)

A modern, full-stack Data Structures and Algorithms (DSA) practice platform built with **Next.js 15**, **FastAPI**, **Supabase (PostgreSQL & Auth)**, and **Judge0**.

---

## 🏗️ Project Architecture

```
PreTest/
├── docs/                 # Documentation & Learning Journal
│   └── LEARNING_JOURNAL.md  # Detailed step-by-step educational guide
├── frontend/             # Next.js 15 App (TypeScript, Tailwind, Monaco Editor)
└── backend/              # FastAPI Server (Python, SQLAlchemy, Pydantic)
```

---

## 🛠️ Tech Stack

- **Frontend**: Next.js 15 (App Router), TypeScript, Tailwind CSS, Monaco Editor, TanStack Query, Zustand, react-markdown.
- **Backend**: FastAPI (Python), SQLAlchemy 2.0, Alembic, Pydantic v2.
- **Database & Auth**: Supabase (PostgreSQL, Supabase Auth, Storage).
- **Code Execution Engine**: Judge0 (Self-Hosted / Cloud API).
